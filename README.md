# NNR home-screen launchers

Each folder is a small page that puts its NNR gauge on a phone home screen and opens that person's page.

- `call/` - run sheet for the Oct 23 call with Cory, Erik and Eric: pages, what moved, the schedule, and what needs a yes. Static, no money on it.
- `golf/` - Golf Crew Tee Sheet for the golf group: calendar, tee times near The Colony, courses, who owes. No money or numbers beyond course phones.
- `lopes/` - joke app page for the golf group text.
